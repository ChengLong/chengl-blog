## Overview

This is a Hugo static site blog (chengl.com, "Random Musings") using the Casper theme, deployed to GitHub Pages via GitHub Actions on push to `main`.

## Commands

```bash
# Local development server with live reload
hugo server

# Build for production (mirrors CI)
hugo --minify && rm -f public/index.xml
```

Hugo version: **0.161.1 extended** (pinned). Install via:
```bash
wget -q https://github.com/gohugoio/hugo/releases/download/v0.161.1/hugo_extended_0.161.1_linux-amd64.deb
sudo dpkg -i hugo_extended_0.161.1_linux-amd64.deb
```

## Architecture

- **Content**: All posts live in `content/post/` as Markdown files named `YYYY-MM-DD-slug.md`
- **Theme**: `themes/casper/` — tracked as regular files (not a git submodule)
- **Static assets**: `static/` — includes `CNAME` for the custom domain
- **Build output**: `public/` — generated by Hugo, deployed as-is to GitHub Pages
- **Config**: `hugo.toml` — site title, base URL, theme, and Casper params

The `public/index.xml` is deleted after build to prevent GitHub Pages from serving the XML feed instead of HTML on the root URL.

## Deployment

Push to `main` triggers `.github/workflows/deploy.yml`, which builds with Hugo and deploys `public/` to GitHub Pages. No manual deploy step needed.
